# Care4purrt
This is our project for managing pet healthcare.
Care4Purrt – Pet Healthcare System (Pet Owner Module)

Care4Purrt is a smart pet healthcare system that helps pet owners manage pet profiles, appointments, moods, personalized care plans, and travel readiness – all in one platform.

Features

Pet Profile Management: Add, edit, view, and delete pet information.

Appointments: Book, update, and cancel vet visits.

MoodTrack: Log daily moods and behavior changes.

CareTailor: Personalized health, nutrition, and exercise recommendations.

PurrPort: Check travel compliance and generate pet passports.

Technology Stack

Frontend: HTML, CSS

Backend: PHP (OOP)

Database: MySQL (phpMyAdmin)

Local Hosting: XAMPP

Installation

Clone the repository:

git clone <repository-url>


Move files to htdocs in XAMPP.

Import the database (care4purrt.sql) in phpMyAdmin.

Update db_connection.php if needed.

Open in browser: http://localhost/care4purrt/
